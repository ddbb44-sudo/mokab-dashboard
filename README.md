# لوحة تحكم منتجات متجر مكعب (Mokab)

هذا المستودع يحتوي على أداة لسحب بيانات المنتجات **العامة الظاهرة للزوار** من متجر [mokab.com](https://mokab.com) (مبني على منصة سلة)، وتحويلها إلى لوحة تحكم تفاعلية واحدة (HTML) بهوية بصرية دافئة وخط IBM Plex Sans Arabic.

## 🔴 اللوحة الحية (بعد رفعها ثم تفعيل GitHub Pages)

ستكون متاحة على: `https://ddbb44-sudo.github.io/mokab-dashboard/`

> ملاحظة: ملف اللوحة (`mokab_dashboard.html`) كبير الحجم (~3 ميجابايت لأنه يضم بيانات ~5000 منتج مضمّنة داخل الملف نفسه)، لذلك يُرفع يدويًا عبر واجهة GitHub (السحب والإفلات) بدل رفعه تلقائيًا. راجع قسم "خطوات الرفع النهائية" أدناه.

## محتوى اللوحة

- بطاقات إحصائية: إجمالي المنتجات، متوفر/غير متوفر، عدد التصنيفات والعلامات التجارية، متوسط السعر، عدد المنتجات المخفّضة ومتوسط نسبة الخصم، متوسط التقييم.
- تحليل: أعلى 8 تصنيفات وأعلى 8 علامات تجارية من حيث عدد المنتجات.
- بحث فوري + فلترة (تصنيف، حالة التوفر) + فرز (سعر، خصم، أبجدي).
- عرض مزدوج: **بطاقات** (صورة أمام كل منتج) أو **جدول** بكل الحقول، مع تنقل بين الصفحات.

## البيانات المسحوبة لكل منتج

الاسم، السعر الحالي، السعر قبل الخصم، نسبة الخصم، التصنيف (المسار الكامل)، العلامة التجارية، الوصف، SKU/رقم الموديل، حالة التوفر، الضمان، متوسط التقييم وعدد المراجعات، رابط المنتج، وصورته.

## طريقة السحب (منهجية موثّقة)

1. **قائمة كل روابط المنتجات**: من ملف `sitemap-2.xml` العام للموقع (يحتوي فعليًا نحو 4999 رابط منتج).
2. **بيانات دقيقة لكل منتج**: عبر واجهة سلة العامة `api.salla.dev/store/v1/products/{id}/details` (لا تحتاج تسجيل دخول ولا مفتاح API — فقط 5 Headers ثابتة، تم اكتشافها بمراقبة طلبات المتصفح الفعلية).
3. **التصنيف والعلامة التجارية**: من صفحة المنتج نفسها عبر بيانات Schema.org (JSON-LD) المضمّنة في كل صفحة (نفس البيانات التي تقرأها جوجل).

## التشغيل

```bash
pip install requests beautifulsoup4 lxml pandas openpyxl
python mokab_scraper.py
```

هذا سيسحب كل منتجات المتجر (~5000، يأخذ 10-20 دقيقة) وينتج ملف `mokab_dashboard.html` بجانب السكربت.

للتجربة السريعة على عدد محدود من المنتجات:

```bash
python mokab_scraper.py --limit 30
```

صيغ إخراج أخرى متاحة: `--format xlsx` أو `csv` أو `json` أو `html` (كتالوج بسيط).

## خطوات الرفع النهائية (لملف اللوحة الكبير) + تفعيل GitHub Pages

1. من صفحة المستودع على GitHub، اضغط **Add file > Upload files**.
2. اسحب ملف `mokab_dashboard.html` من جهازك، وأعد تسميته إلى **index.html** أثناء الرفع (أو بعده من واجهة GitHub) حتى يعمل GitHub Pages من جذر المستودع مباشرة.
3. اذهب إلى **Settings > Pages**، واختر Source: **Deploy from a branch**، Branch: **main** / **(root)**، ثم احفظ.
4. بعد دقيقة أو اثنتين، سيظهر رابط اللوحة الحية في نفس الصفحة (`https://ddbb44-sudo.github.io/mokab-dashboard/`) — شاركه مباشرة مع الفريق.

## ملاحظات

- البيانات عامة تمامًا وظاهرة لأي زائر للموقع؛ لا يتم تجاوز أي حماية أو تسجيل دخول.
- المتجر لا يعرض للزوار أي تفصيل عن توفر منتج معيّن في فرع بعينه (تم التحقق من ذلك) — حالة التوفر عامة على مستوى المتجر الإلكتروني فقط.
