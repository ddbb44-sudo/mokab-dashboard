الداشبورد قيد إعادة الرفع

حدث خطأ تقني أثناء آخر عملية تحديث لهذا الملف عبر واجهة GitHub (انتهى الملف فارغًا بسبب استخدام خاصية "إعادة التسمية" على ملف كبير الحجم لا يقدر محرر الويب على فتحه).

النسخة الصحيحة الكاملة من لوحة التحكم موجودة جاهزة على جهاز صاحب المستودع، وسيتم إعادة رفعها يدويًا قريبًا عبر "Add file → Upload files" مع تسمية الملف مباشرة أثناء الرفع (بدون استخدام خاصية Rename لاحقًا).

هذه صفحة مؤقتة فقط لتفادي ظهور صفحة فارغة تمامًا لحين اكتمال الرفع.
